这是已确认的 V2 首页主体 + 最新 V3 末段询价区和共享页脚。

使用顺序
1. 完整解压 gold-coast-v3-complete.zip，进入 gold-coast-v3 文件夹。
2. 在 Codex 中打开这个文件夹，把 CODEX_PROMPT.txt 的全部内容发给它。
3. 网站现成页面位于 dist。请通过本地 HTTP 服务打开，避免直接双击 HTML 导致以 / 开头的图片、字体、样式和页面链接失效。

Windows 本地预览
有 Python 3 时，可双击 PREVIEW_WINDOWS.bat。
随后打开：http://127.0.0.1:8000/ 或 http://127.0.0.1:8000/zh/
也可以在项目目录终端运行：
python -m http.server 8000 --bind 127.0.0.1 --directory dist
Windows 若只有 py 启动器，改用：
py -3 -m http.server 8000 --bind 127.0.0.1 --directory dist
macOS/Linux 若使用 python3，就把 python 换为 python3。
8000 端口被占用时，把端口号换为 8001，并打开对应地址。
关闭服务窗口或按 Ctrl+C 即可停止预览。

一、从这里开始
1. 将本压缩包完整解压到一个独立目录，保留所有子目录。
2. 让 Codex 打开该目录，把 CODEX_PROMPT.txt 的全文粘贴给它。
3. Codex 先读取 DESIGN.md、README.md 和 CODEX_HANDOFF.md，再启动现有版本。
4. 当前完整站点已在 dist/ 中；源模板是 build.py、src/home_v2.py，双语内容在 src/content.json。

二、直接在本地预览
需要 Python 3，不需要先安装前端依赖。在解压后的项目根目录运行：

python3 build.py
python3 -m http.server 8000 --directory dist

Windows 若没有 python3 命令，可使用：

py -3 build.py
py -3 -m http.server 8000 --directory dist

打开 http://127.0.0.1:8000/ 查看英文首页；打开 http://127.0.0.1:8000/zh/ 查看中文首页。
请通过本地服务访问页面，不要仅双击 index.html，因为站点使用以 / 开头的资源和路由路径。
如在托管 Sites 环境运行，遵循该环境提供的 sites-preview 工作流。
